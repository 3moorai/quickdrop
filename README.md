# QuickDrop

> **Fast, private cross-device peer-to-peer file and text transfer powered by WebRTC.**
> "AirDrop for everyone, regardless of operating system."

QuickDrop allows seamless file, media, text, and link transfers directly between devices across operating systems—iOS, Android, Windows, macOS, Linux, and modern web browsers.

---

## 1. Architecture Overview

QuickDrop utilizes a clean separation between **signaling coordination** and **file data transport**:

```text
               [ Device A ]                       [ Device B ]
                    │                                  │
                    │  1. Create session / Join        │
                    ▼                                  ▼
         ┌────────────────────────────────────────────────────────┐
         │             QuickDrop Signaling Server                 │
         │              (Node.js / Express / WS)                  │
         └────────────────────────────────────────────────────────┘
                    ▲                                  ▲
                    │  2. SDP Offer / Answer Exchange  │
                    │  3. ICE Candidate Exchange       │
                    │                                  │
                    ▼                                  ▼
               [ Device A ] ══════════════════════ [ Device B ]
                             4. Direct WebRTC
                                DataChannel
                               (64 KB Chunks
                              + Backpressure
                              + SHA-256 Check)
```

- **Signaling Server:** Transports session IDs, pairing tokens, SDP offers/answers, and ICE candidates. **File contents never touch the signaling server.**
- **WebRTC DataChannel:** File bytes travel directly between device memories over an encrypted (`DTLS/SCTP`) peer connection.
- **Zero Cloud Storage:** Files are not uploaded, saved, or retained in any cloud database.

---

## 2. Key Features

- **P2P File Transfer:** Zero intermediary cloud storage or account creation required.
- **Chunked Transfer Protocol:** High-throughput 64 KB chunks with native WebRTC DataChannel flow control (`bufferedAmountLowThreshold` backpressure) prevents memory leaks or browser crashes.
- **SHA-256 Integrity Verification:** Mathematical cryptographic hash generated by the Web Crypto API on reconstructed files guarantees zero corruption.
- **Real Transfer Metrics:** True bytes transferred, smoothed throughput in MB/s, and accurate dynamic ETA.
- **QR Pairing & Camera Scanner:** Instant pairing via high-contrast QR code canvas and real mobile camera scanning powered by `jsQR`.
- **Manual Pairing Code:** Fallback 8-character code (`QK-XXXX-XXXX`) or direct shareable URL.
- **Text & URL Transfer:** Dedicated instant text sharing with automatic URL detection, safe open button, and one-click copy.
- **Folder & Image Support:** Multi-file selection, mobile camera capture, and folder uploads where supported (`webkitdirectory`).
- **Dark & Light Mode:** Sophisticated high-contrast UI with responsive desktop and mobile layouts.

## 3. Getting Started

### Prerequisites
- Node.js 20+
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Starts the full-stack server on `http://localhost:3000` with Express backend, WebSocket signaling, and Vite middleware.

### Production Build & Start
```bash
npm run build
npm start
```

### Running Automated Tests
```bash
npm test
```
Executes unit tests covering:
- Filename security sanitization & path traversal prevention
- Size, speed, and ETA calculation logic
- URL safety validation
- Binary packet framing, headers, and parsing
- SHA-256 integrity verification

## 4. STUN & TURN Configuration

QuickDrop defaults to public Google STUN servers for NAT traversal:
- `stun:stun.l.google.com:19302`
- `stun:stun1.l.google.com:19302`

### When is TURN Required?
On networks with strict symmetric NATs or corporate enterprise firewalls (e.g., enterprise Wi-Fi, hospital networks, university dorms), direct peer-to-peer UDP connections may be blocked.

In these environments, configure an encrypted TURN relay server in `.env`:

```env
STUN_SERVER_URL="stun:stun.l.google.com:19302"
TURN_SERVER_URL="turn:turn.example.com:3478"
TURN_USERNAME="quickdrop_user"
TURN_CREDENTIAL="secret_password"
```

> **Note on TURN Privacy:** WebRTC traffic relayed through a TURN server remains end-to-end encrypted using DTLS. The TURN server acts as an opaque packet relay and cannot decrypt or read your file contents.

## 5. Security & Privacy Model

1. **Ephemeral Sessions:** Sessions automatically expire after 15 minutes or when closed by either peer.
2. **Cryptographic Tokens:** Pairing tokens are generated using cryptographically secure random bytes (`crypto.randomBytes`).
3. **Filename Sanitization:** Basenames are stripped of path traversal sequences (`../`), control characters, and OS-restricted characters to prevent arbitrary file overwrite attacks on the receiver.
4. **Link Safety:** Shared URLs require explicit user confirmation to open and are rendered safely without auto-navigation.
5. **No Persistent History:** Transfer history is strictly kept in temporary browser memory for the duration of the session and is wiped when the session terminates.

## 6. Browser Compatibility & Known Limitations

| Platform | Browser | Status | Notes |
| :--- | :--- | :--- | :--- |
| **macOS / Windows / Linux** | Chrome / Edge | Fully Supported | Supports drag & drop, multi-file, folders, WebRTC |
| **macOS / Windows / Linux** | Firefox | Fully Supported | Supports multi-file, WebRTC, QR scanner |
| **macOS** | Safari | Fully Supported | Supports multi-file, WebRTC, drag & drop |
| **Android** | Chrome / Firefox | Fully Supported | Supports camera QR scanning, photos, files |
| **iOS / iPadOS** | Safari | Fully Supported | Supports camera QR scanning; use "Save to Files" to download |

*Note on Mobile Backgrounding:* Mobile operating systems (especially iOS) aggressively suspend background browser tabs. Keep the QuickDrop tab active in the foreground during large file transfers.
